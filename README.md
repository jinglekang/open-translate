# Open Translate

Open Translate 是一个开源 Chromium 翻译插件，支持浏览器内置 Translator API，也支持配置 OpenAI 兼容的大模型接口。默认使用浏览器内置翻译，在浏览器支持对应能力和语言包时，安装后无需配置即可翻译网页选中文本或页面内容。

> 本项目由 AI 辅助开发。

## 功能

- 配置 OpenAI 兼容接口地址，例如 `https://api.openai.com/v1`
- 默认使用浏览器内置 Translator API，无需配置接口地址、模型或 API Key
- 内置翻译会在页面环境中检测源语言，并在检测置信度不足时回退到页面语言
- 配置模型名称、API Key、并发数、批量段数、批量文本长度和自定义系统提示词
- 在选项页维护多套翻译接口
- 在弹窗中快速切换当前翻译接口、目标语言、翻译偏好、翻译范围和翻译方式
- 选中文本后通过右键菜单翻译，并在选区旁边悬浮显示译文
- 未选中文本时通过右键菜单翻译当前页面内容
- 整页翻译支持仅译文替换或双语对照显示
- 页面翻译支持当前视窗模式，滚动后继续翻译进入视窗的内容
- 页面翻译支持段落整体模式，保留行内代码等不翻译片段
- OpenAI 兼容接口使用本地缓存，相同原文和相同配置下会优先复用缓存译文
- 缓存支持数量、估算大小和访问时间统计，最多保留 10,000 条，并可手动删除 30 天未访问的条目
- 支持不翻译白名单、不翻译节点选择器和最小翻译字数
- 支持 Chrome 扩展国际化，目前内置简体中文和英文
- 弹窗和选项页支持跟随系统、浅色和深色主题，并可切换界面语言

1. 更细的缓存策略：在现有 10,000 条 LRU 上限和 30 天旧缓存清理基础上，增加按占用大小限制以及可配置的生命周期和数量阈值。重要程度高，实现难度低到中。
2. 更完整的源语言控制：在现有内置 Translator API 页面与选区语言检测基础上，增加明确的回退选项，并扩展到未来的输入翻译。重要程度高，实现难度中。
3. 双语样式：提供更多双语对照排版、颜色、字号和间距样式。重要程度中到高，实现难度低到中。
4. 悬浮按钮：在网页中提供更快捷的翻译入口和状态控制。重要程度中到高，实现难度中。
5. 站点规则：按网站配置翻译范围、白名单、不翻译选择器和默认翻译偏好。重要程度高，实现难度中到高。
6. 更多翻译引擎：在现有 OpenAI 兼容接口和浏览器内置 Translator API 之外，接入更多大模型、机器翻译服务和浏览器原生能力。重要程度中到高，实现难度中到高。
7. 输入框翻译：在文本框、编辑器和表单输入场景中翻译用户输入。重要程度中，实现难度高。
8. 字幕翻译：支持视频站点字幕识别、翻译和双语字幕显示。重要程度中，实现难度高。
9. 配置迁移与同步：在现有 `chrome.storage.sync` 基础上，增加导入导出或外部同步方式。重要程度中，实现难度中到高。
10. 在线规则订阅：订阅通用规则列表，减少常见网站的手动配置成本。重要程度中，实现难度中到高。
11. 上架发布：完善图标、截图、隐私说明和打包流程，准备发布到 Chrome Web Store。重要程度高，实现难度中，适合在核心功能稳定后推进。

## 开发

```bash
pnpm install
pnpm build
```

构建产物会输出到 `dist`。

项目使用 Vite 多入口构建：

- `src/popup/index.html` 作为插件弹窗入口，`src/popup/main.tsx` 维护快速设置
- `src/options/index.html` 作为插件选项页入口，`src/options/main.tsx` 维护完整扩展设置
- `src/background/index.ts` 作为 Chrome MV3 后台脚本入口，构建后固定输出为 `dist/service-worker.js`
- `src/page/runtime.ts` 作为页面运行时入口，构建后固定输出为 `dist/page-runtime.js`
- `src/shared/settings.ts` 维护配置 schema、zod 校验、旧配置迁移和默认值
- `public/_locales` 维护 Chrome 扩展国际化文案

## 安装到 Chrome

1. 执行 `pnpm build`
2. 打开 Chrome 扩展管理页：`chrome://extensions`
3. 启用“开发者模式”
4. 点击“加载已解压的扩展程序”
5. 选择项目下的 `dist` 目录

## 使用

1. 默认配置使用浏览器内置 Translator API；浏览器支持对应能力和语言包时可直接使用
2. 如需使用 OpenAI 兼容接口，在扩展选项页新增翻译接口并将其设为当前翻译器
3. 点击浏览器工具栏里的 Open Translate 图标，可快速调整翻译设置
4. 在任意网页选中文字，或不选中文本直接右键页面
5. 右键选择“翻译为目标语言”

接口地址会自动拼接 `/chat/completions`。如果你填写的地址已经是完整的 `/chat/completions` 端点，插件会直接使用该地址。

页面翻译会由页面运行时收集文本并分批翻译。弹窗中的翻译范围可在“可见页面”和“当前视窗”之间切换；当前视窗模式会优先翻译屏幕内文本，并在滚动后继续翻译进入视窗的内容。选择“仅译文”时会替换页面文本，选择“双语对照”时会保留原文并插入译文。翻译完成后再次右键页面可选择“显示原文”取消翻译，刷新页面也会恢复原始页面内容。

## 缓存

OpenAI 兼容接口的翻译缓存存放在 `chrome.storage.local`；浏览器内置 Translator API 当前直接在页面环境中翻译，不经过该缓存。缓存 key 会包含接口地址、模型名称、目标语言、自定义提示词、翻译方式和原文内容，因此同一段原文只有在当前配置一致时才会命中缓存。页面翻译会先过滤缓存命中，只把未命中的文本发送给模型。

缓存条目记录创建时间、最近访问时间和译文估算大小。当前最多保留 10,000 条，超过上限时按最近最少使用顺序清理；选项页可以查看缓存统计、清空全部缓存，或删除超过 30 天未访问的带元数据缓存。旧版字符串缓存会在命中时迁移，缓存读写失败不会阻断翻译。
